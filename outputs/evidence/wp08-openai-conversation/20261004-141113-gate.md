### Spend-guard code review

`tests/support/openai_probe.py`'s `SpendTracker`: `before_call()` refuses to start a call if `spent_usd + WORST_CASE_CALL_USD (0.002) > SESSION_GUARD_USD (0.05)`, i.e. a conservative session sub-cap well inside the WP8 USD 0.25 hard cap, and `add()` asserts `spent_usd < WP8_HARD_CAP_USD` after every real cost add using the real `CostCalculator`/`phase0_rate_card()`. This is sane defense-in-depth: a runaway loop of calls would hit the USD 0.05 session guard and raise `RuntimeError` well before the documented USD 0.25 cap, and each call's actual cost is computed from real reported usage (Decimal), not estimated optimistically.
